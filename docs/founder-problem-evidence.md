# 창업자 문제 근거 기록

- 기록일: 2026-08-07 (Asia/Seoul)
- 근거 유형: `founder_lived_experience_n1`
- 판단 범위: `founder_only`
- Gate 1 판단: `passed_for_founder_scope`
- 외부 사용자 수요·빈도·심각도: `not_verified`
- 수집 방법: 제품 책임자의 회고형 자기보고를 구조화한 비식별 요약

## 1. 이 기록의 의미

제품 책임자는 NowSignal의 핵심 문제를 본인이 겪은 여러 유형의 불편에서 선택했다고 확인했다. 이 기록은 창업자 본인의 문제를 해결하는 비공개 탐색을 계속할 근거이며, 다른 사용자나 시장의 수요가 검증됐다는 뜻이 아니다.

정확한 발생일, 사용한 앱 이름, 확인 순서, 지역, 발생 횟수와 소요시간은 이번 기록에서 수집하지 않았다. 독립 관찰이 아닌 회상 기반 자기보고이므로 확인 편향과 기억 오차가 있을 수 있다.

## 3. Gate 1 판단

- Gate 1의 목적을 시장 수요 검증이 아닌 **Founder Problem Fit**으로 제한한다.
- 여러 활동에서 정보 통합 부담과 수치에서 행동으로의 번역 부담이 보고됐으므로 H-P01·H-P02는 `founder_supported_n1`로 둔다.
- H-P03의 활동별 조건 차이는 보조적 `founder_supported_n1`로 둔다. H-P05에는 향후 조건 판단, H-P06에는 대안 선택과 관련된 창업자 근거만 있으며 계획 후 재확인·알림 선호와 대안 탐색 비용을 포함한 전체 가설은 `not_verified`다.
- 신호 충돌을 해결하는 방식 H-P04, Evidence 표시의 효용 H-P07과 위치 권한 없이 핵심 가치가 유지되는지에 관한 H-P08은 이번 경험 기록으로 확인되지 않았다.
- 전체 Gate 1 판단은 `passed_for_founder_scope`이며, 가설을 일반 사용자에게 `validated`로 표시하지 않는다.

## 4. 초기 제품 탐색 범위

### 우선 사용 사례

한국에서 **가까운 외출·산책·러닝의 당일 시각을 정하는 상황**을 첫 범위로 삼는다.

우선 답할 질문은 다음과 같다.

1. 사용자가 나가려는 시각에 비가 올 가능성과 강도가 어떤가?
2. 기온·습도·미세먼지·초미세먼지를 함께 볼 때 야외활동을 그대로 진행할지, 시간을 옮길지, 실내 대안으로 바꿀지 판단할 수 있는가?
3. 우산·마스크·옷차림처럼 결정에 필요한 준비 정보를 근거 시각과 함께 보여줄 수 있는가?

이 범위에서는 기상청 단기예보·실황·기상특보와 AirKorea를 Gate 2 검증 대상으로 유지한다. AirKorea의 이용조건이 해소되지 않으면 대기질 결론을 제외한 날씨 중심 범위로 축소할 수 있다.

### 후속 범위

- 세차와 빨래는 기상 데이터의 유효성이 확인된 뒤 별도 활동 규칙으로 검토한다.
- 나들이·여행·등산·캠핑의 목적지 실제 상황은 지역 Coverage와 현장 정보 Provider를 별도로 검토한 뒤 확장한다.
- 침수·도로·인파·노면·CCTV 정보는 현재 Phase 1 범위에 포함하지 않는다.

## 5. 한계와 외부 검증 Trigger

- 표본은 제품 책임자 1명이며 사용자·연구자·제작자가 동일하다.
- 시장 규모, 다른 사용자의 문제 빈도·심각도, 전환 의향, 지불 의향은 확인하지 않았다.
- 이 기록을 “사용자 조사 완료”, “시장 검증 완료” 또는 제품 효과 근거로 표현하지 않는다.
- 외부 사용자 검증은 외부 참여자 모집·연락·응답 수집, 공개 Beta·출시·홍보, 시장 수요 주장, 유료 운영 확대 또는 창업자 경험에 없던 범위 확장 중 가장 먼저 도래하는 시점 전에 명시적 승인을 받고 재개한다.
- 후속 외부 검증에서는 기존 방식으로 충분했던 반대 사례와 잘못된 추천·과신 가능성을 함께 확인한다.
