## 1. Secret 원칙

공공데이터포털의 [공식 FAQ](https://www.data.go.kr/data/15124045/fileData.do)는 한 서비스키를 여러 OpenAPI에 공통 사용할 수 있고, 재발급하면 기존 키가 폐기된다고 안내한다. 따라서 네 활용신청은 별도 4건으로 제출하되 서비스키는 다음 원칙을 지킨다.

1. 서비스키 선택 단계가 표시되면 `프로젝트 서비스키`와 기존 `NowSignal` 프로젝트를 선택한다.
2. 서비스키 선택 단계가 표시되지 않으면 신청 화면을 그대로 진행하고 승인 후 마이페이지에서 키 유형만 확인한다.
3. `개인 서비스키`로 임의 전환하거나 신규 발급·재발급하지 않는다.
4. 선택 단계는 표시됐지만 기존 `NowSignal` 프로젝트가 보이지 않으면 신청을 제출하지 말고 중단한다.
5. 인증키 원문·일부·Encoded 값은 Chat, 문서, Screenshot, 명령 출력, Shell history, Git에 남기지 않는다.

공식 화면 흐름은 [공공데이터포털 이용가이드](https://www.data.go.kr/ugs/selectPublicDataUseGuideMetView.do)를 우선한다. 현재 화면의 Label이 아래와 다르면 동등한 선택지인지 확인하기 전 제출하지 않는다.

## 3. API별 화면 순서

1. 공식 상세 페이지에서 `활용신청`을 누른다.
2. 신청 유형이 `개발계정`, 심의 여부가 `자동승인`인지 확인한다.
3. 서비스키 선택 단계가 표시될 때만 `프로젝트 서비스키 > NowSignal`을 선택한다. 선택 단계가 없으면 그대로 진행한다.
4. 2절의 활용목적과 해당 API의 활용내용을 입력한다.
5. 첨부파일은 개발 Contract 검증에 필요한 별도 서류가 없으면 비워 둔다.
6. 상세기능의 전체 선택을 해제하고 Runbook에 필요한 기능만 선택한다.
7. 인증유형이 별도로 나오면 기존 프로젝트 키의 `일반 인증키`를 유지하고 신규 발급·재발급하지 않는다.
8. 기상청은 공공누리 제1유형, AirKorea는 공공누리 제3유형으로 표시되는지 확인한다.
9. 이용조건을 읽고 화면이 이 가이드와 일치할 때만 신청한다.
10. 네 API 각각에 대해 같은 절차를 반복한다.

### 2026-08-10 기상청 단기예보 신청 화면 확인

- `개발계정`, `자동승인`, 승인일부터 24개월 활용 가능으로 표시됐다.
- 서비스키 선택 단계는 표시되지 않았다.
- 활용목적 `웹 사이트 개발`, 설명 입력, 선택적 첨부파일, 상세기능 선택과 공공누리 제1유형 동의가 표시됐다.
- `전체기능`을 해제하고 `초단기실황조회`, `초단기예보조회`, `단기예보조회`만 선택한다.
- 위치기반서비스 사업자 신고 안내가 표시됐다. 이번 개발 검증은 사용자 위치 없이 고정 공개 격자만 사용하며 첨부파일을 제출하지 않는다. 이 선택은 NowSignal Production의 신고 적용 여부를 해소하지 않으며, 실제 위치 기능 설계·배포 전 별도 확인 대상으로 남긴다.

## 4. 신청 후 확인

`마이페이지 > 데이터 활용 > Open API > 활용신청 현황`에서 다음 비밀이 아닌 항목만 확인한다.

| 확인 항목 | 기대값 |
| --- | --- |
| API ID | `15084084`, `15000415`, `15073861`, `15073877`이 각각 별도 행 |
| 신청 유형 | `개발계정`, `활용신청` |
| 처리 상태 | `승인` 또는 실제 화면 상태 |
| 서비스키 유형·프로젝트명 | 화면에 표시되는 경우 유형과 프로젝트명만 확인 — 키 값 아님. 신청 화면에 선택 단계가 없었다면 프로젝트 키라고 추정하지 않음 |
| 승인 일일 Traffic | KMA 각 10,000, AirKorea 각 화면 500 예상. 다르면 실제 값을 우선 |
| 활용기간 | 화면에 표시된 시작일·종료일 |
| 신청일·승인일 | 화면 표시 날짜 |

공개 저장소에는 API ID, 상태, 키 유형, 프로젝트명, 승인 Traffic, 활용기간과 날짜만 기록한다. 인증키, 키 일부, 신청번호, 계정명, Email과 전화번호는 기록하지 않는다. Screenshot에 키나 식별정보가 보이면 Screenshot을 공유하지 말고 위 항목만 Text로 전달한다.

## 5. 즉시 중단 조건

다음 중 하나면 신청을 제출하거나 다음 API로 넘어가지 않는다.

- 서비스키 선택 단계는 표시됐지만 기존 `NowSignal` 프로젝트 서비스키가 보이지 않음
- 신규 키 발급 또는 기존 키 재발급만 선택 가능
- `운영계정`이 기본 선택이고 `개발계정`으로 바꿀 수 없음
- 공개 페이지보다 실제 승인 Traffic이 낮거나 이용조건·License가 다름
- AirKorea 화면이 운영용 위치 관련 증명이나 추가 서류를 요구함
- 인증키가 URL, Screenshot, Clipboard history 또는 명령 출력에 노출됨

`15084084` 신청 화면의 상세기능별 공개 값은 10,000회/일이었지만 승인 결과 화면에는 일일 Traffic이 표시되지 않았다. 따라서 실제 승인량은 마이페이지의 활용신청 상세 또는 사용자 지원 API로 확인하기 전 `not_verified`다. 인증키·신청번호·계정 식별정보는 확인하거나 기록하지 않았다.
